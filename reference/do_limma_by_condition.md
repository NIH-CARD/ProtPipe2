# Perform DEA using the condition labels of the protdata object

Perform DEA using the condition labels of the protdata object

## Usage

``` r
do_limma_by_condition(object, condition, control_group, treatment_group)
```

## Arguments

- condition:

  the name of a column in the condition slot that contains the
  comparison group names.

- control_group:

  the name of the control group

- treatment_group:

  the name of the treatment group
