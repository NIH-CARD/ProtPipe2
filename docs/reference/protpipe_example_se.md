# Example SummarizedExperiment for ProtPipe workflows

A packaged `SummarizedExperiment` created from
`EXAMPLES/basic_example_data/iPSC.csv`. The object contains
protein-level abundance measurements and row metadata from the source
file. No external sample metadata are supplied during construction;
`colData` contains a single `differentiation_day` column derived from
the autogenerated `base_condition` values produced by
[`create_se()`](https://nih-card.github.io/ProtPipe2/docs/reference/create_se.md).

## Usage

``` r
protpipe_example_se
```

## Format

A `SummarizedExperiment` object with one assay named `intensities`.

## Source

`EXAMPLES/basic_example_data/iPSC.csv`

## Details

This dataset is intended for examples, tests, and the getting-started
vignette.
